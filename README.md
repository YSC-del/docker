# 蛋糕商城用户注册页面

这是一个使用HTML、CSS、JavaScript和Bootstrap框架开发的蛋糕商城用户注册页面。

## 项目特性

### 🎨 界面设计
- 现代化的响应式设计
- 美观的渐变色彩搭配
- 流畅的动画效果
- 移动端友好的布局

### 🧩 功能组件
- **导航栏**: 包含首页、商品分类、热销、新品、注册、登录等链接
- **搜索功能**: 带有搜索框和购物车入口
- **注册表单**: 完整的用户信息收集
- **页脚**: 友情链接和版权信息

### 📋 表单字段
- 用户名（3-20个字符，支持中英文数字）
- 邮箱地址（格式验证）
- 密码（6-20位，包含字母和数字）
- 确认密码（与密码匹配验证）
- 收货人姓名（2-10个字符）
- 联系电话（11位手机号验证）
- 收货地址（省市区联动选择 + 详细地址）
- 用户协议同意确认

### ✅ 表单验证
- 实时输入验证
- 详细的错误提示信息
- 视觉反馈（成功/错误状态）
- 防重复提交保护

### 🎯 交互效果
- Bootstrap下拉菜单（使用data-toggle="dropdown"）
- 密码显示/隐藏切换
- 地址三级联动选择
- 搜索功能
- 购物车计数器
- 平滑滚动效果

## 技术栈

- **HTML5**: 语义化标签结构
- **CSS3**: 自定义样式和动画
- **JavaScript ES6+**: 表单验证和交互功能
- **Bootstrap 5.3**: 响应式框架和组件
- **Bootstrap Icons**: 图标库

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 或者使用本地服务器运行项目

### 使用本地服务器（推荐）
```bash
# 使用Python
python -m http.server 8000

# 使用Node.js
npx serve .

# 使用PHP
php -S localhost:8000
```

然后在浏览器中访问 `http://localhost:8000`

## 自定义配置

### 颜色主题
在 `styles.css` 文件的 `:root` 选择器中修改CSS变量：

```css
:root {
    --primary-color: #e91e63;    /* 主色调 */
    --secondary-color: #ff4081;  /* 辅助色 */
    --accent-color: #ffc107;     /* 强调色 */
}
```

### 验证规则
在 `script.js` 文件的 `validationRules` 对象中修改验证规则。

## 注意事项

1. 项目使用CDN加载Bootstrap和图标库，需要网络连接
2. 表单提交目前是模拟功能，实际项目需要配置后端接口
3. 地址数据是示例数据，实际使用需要完整的地址库
