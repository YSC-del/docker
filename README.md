# 蛋糕商城用户注册页面

这是一个使用 HTML + CSS + JavaScript + Bootstrap 开发的蛋糕商城用户注册页面项目。

## 项目结构

```
├── index.html          # 首页演示页面
├── register.html       # 用户注册页面
├── styles.css          # 自定义样式文件
├── script.js          # JavaScript功能文件
└── README.md          # 项目说明文档
```

## 功能特性

### 🎨 界面设计
- **现代化UI设计**：采用渐变色彩和卡片式布局
- **响应式布局**：支持桌面端、平板和手机端
- **动画效果**：页面加载动画、悬停效果、过渡动画
- **图标支持**：使用Font Awesome图标库

### 🧭 导航栏功能
- **响应式导航菜单**：支持移动端折叠菜单
- **搜索框**：支持关键词搜索功能
- **购物车入口**：显示购物车商品数量
- **下拉菜单**：商品分类下拉菜单，支持鼠标悬停效果

### 📝 注册表单功能
- **完整表单字段**：
  - 用户名（3-20位，支持中文、英文、数字、下划线）
  - 邮箱地址（标准邮箱格式验证）
  - 密码（至少8位，包含字母和数字）
  - 确认密码（与密码一致性验证）
  - 收货人（2-10位，支持中文和英文）
  - 联系电话（11位手机号码验证）
  - 收货地址（10-100位详细地址）
  - 服务条款同意

### ✅ 表单验证
- **实时验证**：输入时即时验证并显示结果
- **密码强度验证**：确保密码包含字母和数字
- **邮箱格式验证**：标准邮箱格式检查
- **手机号验证**：11位中国大陆手机号格式
- **密码一致性**：确认密码与密码一致性检查
- **必填项验证**：所有必填项完整性检查

### 🔧 交互功能
- **密码显示/隐藏**：点击眼睛图标切换密码可见性
- **表单自动保存**：本地存储表单数据，防止意外丢失
- **提交状态反馈**：加载动画和成功/错误提示
- **键盘导航**：支持Tab键导航和Enter键提交
- **ESC键关闭**：按ESC键关闭下拉菜单

### 📱 响应式设计
- **移动端优化**：针对手机屏幕优化布局
- **平板适配**：中等屏幕尺寸的布局调整
- **桌面端体验**：大屏幕的最佳显示效果

## 技术栈

- **HTML5**：语义化标签，表单验证属性
- **CSS3**：Flexbox布局，Grid布局，动画效果
- **JavaScript ES6+**：现代JavaScript语法
- **Bootstrap 5**：响应式框架，组件库
- **Font Awesome 6**：图标库

## 使用方法

1. **直接打开**：
   - 在浏览器中打开 `index.html` 查看演示
   - 点击"查看注册页面"按钮进入注册页面

2. **本地服务器**（推荐）：
   ```bash
   # 使用Python启动本地服务器
   python -m http.server 8000
   
   # 或使用Node.js
   npx http-server
   ```

3. **访问地址**：
   - 首页：`http://localhost:8000/index.html`
   - 注册页面：`http://localhost:8000/register.html`
